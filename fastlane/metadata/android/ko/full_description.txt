여러분의 주머니 속에 3D 자기장 센서가 들어있다는 사실을 알고 계셨나요? 휴대폰을 진자로 활용하여 지역의 중력가속도를 측정하거나, 휴대폰을 음향 탐지기(소나)로 변환할 수 있다는 사실을 알고 계셨나요?

Phyphox는 휴대폰의 센서에 직접 접근하거나 바로 실행 가능한 실험을 제공하여 데이터를 분석해 줍니다. 또한 추가 분석을 위해 결과와 함께 원시 데이터를 내보낼 수 있습니다. phyphox.org에서 나만의 실험을 직접 정의하고 동료, 학생, 친구들과 공유할 수도 있습니다.

주요 기능: 
• 사전 정의된 다양한 실험 제공. 재생 버튼만 누르면 바로 시작됩니다.
• 널리 사용되는 다양한 형식으로 데이터 내보내기 가능
• 휴대폰과 동일한 네트워크에 있는 모든 PC의 웹 인터페이스를 통해 실험을 원격 제어. PC에 별도의 프로그램을 설치할 필요 없이 최신 웹 브라우저만 있으면 됩니다.
• 웹 에디터(<a href="http://phyphox.org/editor">http://phyphox.org/editor</a>)를 사용해 센서 입력을 선택하고 분석 단계를 정의하며 인터페이스 화면을 생성하여 나만의 실험을 직접 구성할 수 있습니다. 단순한 두 값의 합산부터 푸리에 변환 및 상호 상관 분석과 같은 고급 알고리즘까지 다양한 분석 도구를 제공합니다.

지원 센서: 
• 가속도계 
• 자기장 센서 
• 자이로스코프 
• 조도 센서 
• 기압계 
• 마이크 
• 근접 센서 
• GPS 
*일부 센서는 기기에 따라 탑재되어 있지 않을 수 있습니다.

내보내기 형식: 
• CSV (쉼표로 구분된 값) 
• TSV (탭으로 구분된 값) 
• Excel 
(만약 다른 형식이 필요한 경우 알려주세요)

요청 권한 설명

Android 6.0 이상을 사용하는 경우, 권한은 필요한 시점에만 요청됩니다.

인터넷: phyphox에 네트워크 접근 권한을 부여하며, 온라인 리소스에서 실험을 불러오거나 원격 접속을 사용할 때 필요합니다. 두 기능 모두 사용자가 요청할 때만 수행되며 다른 데이터는 전송되지 않습니다.
블루투스: 외부 센서에 접근하는 데 사용됩니다.
외부 저장용량 읽기: 기기에 저장된 실험을 열 때 필요할 수 있습니다.
오디오 녹음: 실험에서 마이크를 사용하는 데 필요합니다.
위치: GPS에 접근 권한은 위치 기반 실험을 위해 사용됩니다.
카메라: 외부 실험 구성을 위한 QR 코드를 스캔하는 데 사용됩니다.
